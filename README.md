# Internship Data Science & Machine Learning Tasks

## Project Overview

This repository contains the Data Science and Machine Learning tasks
completed during my internship.

The project covers data analysis, exploratory data analysis,
customer segmentation, natural language processing, classification,
regression, fraud detection, and basic language-modeling techniques.

The tasks were implemented primarily using Python and executed using
Kaggle Notebooks.

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Kaggle
- Jupyter Notebook

## Project Tasks

### Level 1

#### Task 1 — Retail Sales Analysis

Dataset: Retail Sales Dataset

Main activities:

- Data loading and cleaning
- Exploratory data analysis
- Sales analysis
- Product-category analysis
- Monthly sales trends
- Customer analysis
- Data visualization

#### Task 2 — Customer Segmentation

Dataset: Retail Sales Dataset

Main activities:

- Frequency calculation

- Elbow method

#### Task 3 — Retail Customer & Product Insights

Dataset: Retail Sales Dataset

Main activities:

- Customer spending analysis
- Product-category analysis
- Quantity and sales analysis
- Correlation analysis
- Data visualization

#### Task 4 — IMDB Sentiment Analysis

Dataset: IMDB Movie Reviews Dataset

Main activities:

- Text preprocessing
- Text cleaning
- TF-IDF vectorization

- Accuracy evaluation

- Confusion matrix

Dataset: Google Play Store Apps Dataset

## Notebook

The complete implementation is available in:

`notebooks/Kaggle_Internship_9_Tasks.ipynb`

visualizations, model training, evaluation and analysis for all tasks.

## How to Run

1. Open the notebook using Kaggle or Jupyter Notebook.
2. Add the required datasets to the Kaggle environment.
3. Verify the dataset paths.
4. Run the notebook cells sequentially.
5. Review the generated visualizations, tables and model evaluation
   results.
