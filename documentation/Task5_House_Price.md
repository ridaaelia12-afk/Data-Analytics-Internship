# Task 5 — House Price Prediction

## Overview

This task focuses on predicting house sale prices using property
features.

The problem is treated as a supervised regression task.

## Dataset

**Dataset:** House Prices Dataset

**File:** `train.csv`

### Dataset Size

- Rows: 1,460
- Columns: 81

The dataset contains property characteristics and a target variable:

`SalePrice`

## Objectives

The objectives were:

1. Explore the housing dataset.
2. Handle missing values.
3. Prepare numerical and categorical features.
4. Encode categorical variables.
5. Train regression models.
6. Evaluate prediction performance.
7. Compare model results.

## Data Preprocessing

The preprocessing included:

- Identifying missing values.
- Handling numerical missing values.
- Handling categorical missing values.
- Separating features and target.
- Encoding categorical variables.
- Preparing the data for machine learning.

## Target Variable

The target variable is:

`SalePrice`

This represents the sale price of a house.

## Models

The regression models include:

- Linear Regression
- Random Forest Regression

## Evaluation Metrics

The models were evaluated using:

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

## Analysis

Model performance was compared using the evaluation metrics.

The results show how different machine learning approaches perform
when predicting house prices from property characteristics.

## Tools

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Conclusion

House price prediction demonstrates how supervised machine learning
can be applied to real-world regression problems. Property
characteristics can be used to estimate the expected selling price
of a house.
